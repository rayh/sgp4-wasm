About

SGP4/SDP4 propagation runs locally in WebAssembly (pkg/sgp4_wasm_bg.wasm), wrapping the Rust sgp4 crate. Output is TEME ECI position/velocity plus WGS84 geodetic coordinates.

The Moon is positioned with a Meeus lunar ephemeris; Earth rotation uses GMST.

Object metadata via ESA DISCOSweb, TLEs via Celestrak.
