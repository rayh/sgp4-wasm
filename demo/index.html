About

Every dot is a live SGP4 propagation running locally in WebAssembly (pkg/, wrapping the Rust sgp4 crate). The full catalog is re-propagated several times a second; time is always live and can be scrubbed ±24 h.

Output is TEME ECI position/velocity plus WGS84 geodetic coordinates. The Moon uses a Meeus lunar ephemeris; Earth rotation uses GMST.
